rclone-dissertation

A private backup client for one researcher's own Google Drive

What this app is

rclone-dissertation is the name of an OAuth client used by rclone, an open-source file synchronisation tool. It is run by a single researcher, Sangwook Joo, to copy the owner's doctoral dissertation materials (manuscripts, figures, documents and experiment records) from the owner's research computer to the owner's Google Drive.

Who uses it

Only the owner. The app is not offered to the public, has no other users, and does not sign anyone else in.

What it does with Google Drive

  • Uploads and updates files in the owner's own Google Drive folders.
  • Lists those folders to check which files are already there.
  • Does not read, collect, analyse or share anyone else's data.
